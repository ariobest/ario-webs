Script API

Private source delivery with server-side key validation, expiry and usage limits.

Checking API configuration…
Validate a key

POST JSON with action, key, and the published script slug.

{"action":"validate","key":"YOUR_KEY","script":"your-script-slug"}
Load authorized source

POST the same fields with action: "load". The API returns Lua source as plain text only after validation.

{"action":"load","key":"YOUR_KEY","script":"your-script-slug"}

Security note: keys are stored as SHA-256 hashes and checked server-side. Code returned to a client can still be inspected by that client; this API protects access, not against all reverse engineering.
